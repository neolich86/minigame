# Playtest Report (화면 점검)

Claude Code Game Studios(MIT)의 playtest-report를 '사람 테스터 메모 정리'가 아니라 'Claude가 직접 화면을 보고 고치기'로 바꾼 것.

1. **재현** — Playwright(모바일 390×844)로 `?test` 를 열고 문제 상황을 만든다(파티 구성, 웨이브, 스킬 사용 등 훅으로 강제).
2. **연속 캡처** — 60~120ms 간격 30~50장 → 4열 그리드 한 장으로 합쳐서 본다. 필요한 부분은 확대(clip, deviceScaleFactor 3).
3. **점검 목록**
   - 캐릭터 방향·걷기 프레임 순서·발 위치(공중에 뜨거나 미끄러짐)
   - 공격 모션이 실제 맞는 순간과 맞는지, 근접은 붙어서 싸우는지
   - 크기 비율(영웅·적·건물), 카메라 각도, 그림자
   - HUD·버튼·말풍선에 전투가 가리는지, 글자 겹침
   - 화면 밖에서 죽거나 생기는 것
   - 콘솔 에러
4. **보고** — 문제마다: 무엇이 / 왜(원인 코드) / 어떻게 고침. 고친 뒤 같은 방법으로 다시 캡처해 전/후 이미지를 보낸다.
5. 그림 자체가 부족하면(예: 옆모습 공격 프레임 없음) 필요한 그림을 구체적으로(프레임 수·방향·크기) 사용자에게 요청한다.
