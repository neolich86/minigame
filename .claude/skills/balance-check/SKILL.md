# Balance Check (봇 시뮬)

Claude Code Game Studios(MIT)의 balance-check을 '수치 읽기'가 아니라 '실제로 돌려 보기' 방식으로 고친 것.

1. **목표 확인** — 명세의 "밸런스 목표"를 읽는다(없으면 장르 기준을 제안하고 사용자에게 확인).
2. **봇 만들기** — 스크래치에 시뮬 스크립트.
   - 규칙이 `core.js` 에만 있으면 node로 import 해서 dt 0.05 로 수 시간 분량을 돌린다.
   - three.js 등 화면과 얽혀 있으면 Playwright로 `?test` 를 열고 `frozen=true` 후 `update(.05)` 를 반복한다.
   - 봇은 적어도 두 종류: **열심히 하는 봇**(돈 생기면 바로 투자·스킬 사용)과 **대충 하는 봇**(투자 적게).
3. **기록** — 10분(또는 웨이브)마다 진행도·자원·전투력 한 줄. 이정표(첫 동료, 전직, 보스, 패배 시점)를 따로 표로.
4. **판정** — 목표와 비교: 너무 빠름 / 맞음 / 너무 느림 / 막힘(진행이 멈추는 구간). 돈이 남아도는지, 한 가지 선택만 압도적인지 확인.
5. **조정** — 바꿀 값은 2~4개만, 왜 바꾸는지 한 줄씩. 바꾼 뒤 같은 봇으로 다시 돌려 전/후를 표로 보여 준다.
