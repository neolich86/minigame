# Brainstorm (웹 게임용)

Claude Code Game Studios(MIT)의 brainstorm을 미니게임천국 웹 게임에 맞게 줄인 것.

1. **재료 확인** — 받은 에셋(압축은 풀어서 종류·애니메이션·라이선스), 레퍼런스 게임, 기존 비슷한 게임(`src/lib/games.ts`, 프로젝트 문서)을 먼저 본다. 레퍼런스는 규칙만 참고하고 이름·그림은 가져오지 않는다.
2. **후보 3~5개** — 각각 한 줄 콘셉트 · 핵심 재미(10초 안에 이해되는가) · 한 판 길이 · 성장/재방문 이유 · 필요한 에셋 · 만들기 난이도(하/중/상). 모바일 세로 화면에서 한 손으로 되는지 표시.
3. **추천 하나** — 이유 2~3줄. 이미 있는 게임과 겹치면 말한다.
4. 사용자가 고르면 한 페이지 콘셉트(이름 후보 3개 포함)를 정리하고 `/quick-design` 으로 넘어간다.

질문은 꼭 필요한 것 하나만. 고르기 쉬운 선택지로.
