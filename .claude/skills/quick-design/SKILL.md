# Quick Design (웹 게임 명세)

Claude Code Game Studios(MIT)의 quick-design을 미니게임천국 방식으로 줄인 것.

## 명세 형식 — 프로젝트 문서 `claude/<게임이름>-명세.md` (Projects 도구로 저장)
```
# <게임 이름> — 명세 v0.1
## 0. 확정 사항        (사용자가 정한 것만, 정한 그대로)
## 1. 화면 구성         (모바일 세로: 위 HUD / 가운데 플레이 / 아래 버튼)
## 2. 핵심 규칙         (한 판의 흐름, 승리·패배)
## 3. 성장 · 경제       (재화, 비용 곡선, 보상 — 수치는 표로)
## 4. 콘텐츠           (스테이지·적·스킬·아이템 목록)
## 5. 에셋             (팩 이름 · 라이선스 · 확인 여부)
## 6. 기술             (public/games/<id>/ · core.js/game.js · 저장 · 랭킹)
## 7. 첫 버전 범위      (만들 것 / 다음으로 미룰 것)
## 8. 밸런스 목표       (예: 첫 동료 4분, 1차 전직 3시간)
## 9. 버전 기록
```

## 순서
1. 기존 명세가 있으면 먼저 읽고 고친다(버전 올림). 없으면 새로 만든다.
2. 정하지 않은 중요한 것(이름, 진행 방향, 수익 방식 등)만 한 번에 묶어 묻는다. 작은 것은 합리적으로 정하고 명세에 "가정"으로 적는다.
3. 수치는 `/balance-check` 로 검증할 목표 형태로 쓴다.
4. 저장 후 사용자에게 바뀐 점만 짧게 알린다.
